# Light & Optics Studio

A dependency-free educational optics sandbox built with HTML, CSS, and vanilla JavaScript. The root `index.html` can be served directly by GitHub Pages.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static file server.

The ray sketches use a simplified ideal ray model. Real light also behaves as a wave; effects such as diffraction, interference, and detailed image quality are outside this model.
